💡 Cara Menambah Profil Akun Baru via CLI:

./youtube-autoposter -profile "akun_dua"

Ini akan membuka browser OAuth2 untuk login akun kedua dan menyimpannya di file token_akun_dua.json. Profil akan otomatis muncul di Web UI ini.
